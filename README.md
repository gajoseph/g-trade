# g-trade

A Python-based trading application for automated trading strategies.

## Features

- Automated trading strategy execution
- Real-time market data processing
- Portfolio management
- Trade history and reporting

## Requirements

- Python 3.9+
- See `requirements.txt` for dependencies

## Installation

```bash
git clone https://github.com/gajoseph/g-trade.git
cd g-trade
pip install -r requirements.txt
```

## Usage

```bash
python -m gtrade
```

## Project Structure

```
g-trade/
├── gtrade/          # Main package
│   ├── __init__.py
│   ├── main.py      # Entry point
│   ├── strategies/  # Trading strategies
│   └── utils/       # Utility modules
├── tests/           # Test suite
├── requirements.txt
└── README.md
```
